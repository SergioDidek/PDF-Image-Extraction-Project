## Sobre o Projeto
Este projeto foi construído por mim para fins de freelancer e enriquecimento do meu portfólio/repositórios. Ele é um script em Python que extrai imagens de arquivos PDF mantendo os formatos e dimensões originais de forma totalmente automatizada. 

Ao final da execução, o sistema organiza os arquivos gerados com a estrutura `images_{index}`, compacta tudo em um arquivo `.zip` e gera um relatório em texto com os detalhes de tudo o que foi extraído.

---

## Stack do Projeto
* Python
* Pathlib
* PyPDF
* Zipfile
