## Sobre o Projeto
Este projeto foi construído por mim para fins de freelancer e enriquecimento do meu portfólio/repositórios. Ele é um script em Python que extrai imagens de arquivos PDF, colocados na pasta Input,  mantendo os formatos e dimensões originais de forma totalmente automatizada. 

Ao final da execução, o sistema organiza os arquivos gerados com a estrutura `images_{index}`, compacta tudo em um arquivo `.zip` e gera um relatório em texto com os detalhes de tudo o que foi extraído.

* Zipfile

## 🇺🇸 English Version

## About The Project
This project was built by me for freelance purposes and to enrich my professional portfolio. It is a Python script that automatically extracts images from PDF files placed in the Input folder, keeping their original formats and dimensions in a fully automated workflow.

After running, the system organizes all extracted assets using the `images_{index}` structure, compresses them into a single `.zip` file, and generates a text report with the metrics of the processed files.

* Python
* Pathlib
